SheBuilds Dashboard

Real-time hackathon dashboard — help & reference guide

Overview

SheBuilds Dashboard is a real-time hackathon dashboard that displays live statistics, trending topics, builder spotlights, an activity feed, and a countdown timer. Data is managed through a browser-based admin panel accessible from any device.

The dashboard updates automatically via WebSocket — no manual refresh is needed.

PageURLWho uses it
Dashboard / Projected on screen during the event (read-only live view)
Admin Panel /admin Organiser — manage builders, stats, topics (password required)
Builder Submit /submit Hackathon participants — submit their app

Dashboard Display

The main dashboard at / is designed to be projected on a large screen. It shows:

  • Stats Row — Active Builders, Completed Apps, In Progress (auto-calculated), and a Countdown Timer
  • Builder Spotlight — Featured builder with their project details, set by the admin
  • Live Activity Feed — Real-time stream of builder actions and milestones
  • Trending Topics Word Cloud — Visual display of popular app topics

Administrator Guide

Accessing the Admin Panel

Navigate to /admin. The admin panel is mobile-friendly and works on phones, tablets, and desktops. A password prompt is shown on first visit — see Password Gate below.

Password Gate

The admin panel is protected by a password to prevent unauthorised changes to the live dashboard during the event.

  1. Navigate to /admin — a lock screen is displayed
  2. Enter the admin password provided by the event organiser and click Enter
  3. On success you are taken directly to the admin panel
  4. Your session remains active for the duration of the browser tab — closing the tab or browser requires re-authentication

If you see "Incorrect password", double-check the password (it is case-sensitive) and try again. The field clears automatically on each failed attempt.

Organiser note: The password is pre-configured before the event. To change it, update the hash in src/lib/adminConfig.ts using a SHA-256 of the new password and redeploy.

Settings Tab

Hackathon Timing

  1. Set the Hackathon Start Time and End Time to control the countdown timer
  2. Click Set to Now (+3h end) to use the current time as start and auto-set end time 3 hours later
  3. Click Save Settings — changes appear on the dashboard immediately

Trending Topics

  1. Enter a topic name and set its weight (1–10; higher weight = larger text in the word cloud)
  2. Click Add Topic
  3. Delete topics with the trash icon

Builders Tab

Import from CSV

  1. Click the upload area under Import from CSV and select your Luma guest export CSV
  2. The importer automatically detects columns by fuzzy name match (Name, Email, Ticket, Check-in Status)
  3. Click Import Builders
  4. Duplicates are automatically skipped (matched by Luma guest ID, email, or ticket number)
  5. After import, the Active Builders count updates automatically and an import summary is shown

Builder List

  • Search — Filter by name, email, or ticket number
  • Each row shows: avatar, name, badges (Spotlight / Checked-in), build status emoji, project name
  • Edit (pencil icon) — Opens the inline edit panel
  • Spotlight (star icon) — Features the builder in the dashboard spotlight (only one at a time)
  • Delete (trash icon) — Removes the builder

Edit Panel (inline)

When you click the pencil icon on a builder row, an edit panel opens below it:

  • App Name — 25 characters max
  • App Topic — 25 characters max; starts autocomplete suggestions from existing topics
  • Build Status — Dropdown: designing / building / testing

Changing the build status automatically posts an activity entry to the live feed.

Post Activity

Manually post a custom activity entry for a builder:

  • Enter action text (500 characters max) and select an emoji (10 options)
  • Click Post Activity — appears on the dashboard feed immediately

Recent Activity

Lists the last 50 activity entries. Delete individual entries with the trash icon.

Builder Guide

Submitting Your App

  1. Navigate to /submit
  2. Fill in the form:
    • Full Name (required) — Your name as you'd like it displayed (min 2 characters)
    • Email (required) — Your contact email
    • App Name (required) — 25 characters max
    • App Topic (optional) — Short description of your app (25 characters max); shows autocomplete suggestions
    • App Link (optional) — URL to your deployed app; must start with http:// or https://
  3. Click Submit App
  4. On success you'll see a confirmation screen with an option to view the live dashboard

What Happens After You Submit

  • Your submission is recorded and deduplicated by email — re-submitting updates your existing entry
  • The In Progress count on the dashboard updates automatically (calculated as Active Builders − distinct submitters)
  • An activity entry appears in the live feed with your name and app name
  • An administrator may feature your project in the Builder Spotlight

Troubleshooting

MessageWhat to do
"Full name must be at least 2 characters"Enter your full name.
"Please enter a valid email address"Check your email format.
"App name is required"App name cannot be blank.
"App name must be 25 characters or less"Shorten your app name.
"App topic must be 25 characters or less"Shorten your app topic description.
"Please enter a valid URL"Make sure your link is a complete URL starting with https:// (e.g. https://your-app.example.com). Plain http:// links are also accepted. Links without a protocol are rejected.
